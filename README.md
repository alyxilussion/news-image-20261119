# The World Today — 19 November 2026 (v2)

A fresh, legible take on the day's news: five big illustrated stories and
ten one-liners, set as a one-page broadsheet. This is version 2 of the
entry, rebuilt after v1's dense 45-story layout scored below the pay line —
fewer stories, much larger type, every headline readable at the size the
judge sees.

The five heroes: the first Trump–Xi–Putin summit in Shenzhen; the ICJ's
genocide ruling against Myanmar; Anthropic's record $81.3bn IPO; GTA VI's
launch after 13 years; Cyclone Akvan's evacuations in Odisha. The ten
one-liners cover the rest of the day across all six continents.

The image is drawn by hand with Python/PIL (flat vector-style
illustrations, DejaVu type). `main.ts` copies it to `/output/entry.png`
and verifies the PNG signature, size and dimensions before finishing.
